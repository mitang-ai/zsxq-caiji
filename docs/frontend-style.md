# 前端样式规范

集见是读资料、选材料和改稿的工作台，不是大字营销海报。公开介绍与应用使用同一套黑白基础色；不靠暖纸色、巨型标题、装饰分隔符或自动播放动画制造识别度。

## 基础规则

| 项目 | 浅色 | 深色 |
| --- | --- | --- |
| 页面 | `#FFFFFF` | `#181818` |
| 侧栏 | `#F7F7F7` | `#141414` |
| 面板 | `#FFFFFF` | `#202020` |
| 悬停 | `#F2F2F2` | `#2A2A2A` |
| 正文 | `#202020` | `#EEEEEE` |
| 次级文字 | `#666666` | `#AAAAAA` |
| 分隔线 | `#E5E5E5` | `#363636` |

- 系统字体：Apple 系统字体优先，Windows 使用 Segoe UI，中文回退到 PingFang SC 和 Microsoft YaHei。无需下载字体。
- 应用标题 24px，公开标题桌面 28px、手机 24px，节标题 18px，正文 15px，辅助文字 12–13px。阅读器默认 17px，保留用户调节与浏览器缩放。
- 间距按 4px 网格，普通分组 16–24px。控件圆角 5–6px，不做胶囊按钮、漂浮大卡片或渐变。
- 公共介绍用侧边索引和正文行，下载页用真实文件表格。应用延续侧栏、列表、阅读器与检查面板，不改成相同大小的功能卡片墙。
- 不用斜杠、中点或圆点分隔品牌、导航和元信息。URL、文件路径、真实比例和列表语义不受此限制。
- 彩色只用于确有含义的错误、警告、成功和信息提示，状态同时提供文字，不依赖颜色辨认。
- Logo 在导航里使用 26–32px；无自动品牌入场动画。加载和进度反馈只对应真实任务。

## 外观行为

提供「浅色」「深色」「跟随系统」。系统模式监听设备偏好变化；手动选择不被系统变化覆盖。公开页、账号页和工作台都有入口，插件在外观设置中提供相同选择。

偏好只保存在当前设备。旧 `warm` 和 `mist` 值映射到浅色，其他阅读设置不丢弃。原有存储键、账号和配对协议不变。

## 验收

自动测试检查背景为中性灰阶、标题字号上限、明暗切换、系统变化、刷新保留、旧主题迁移与登录不丢失。公开页检查 320px、390px 与桌面渲染；工作台继续运行原有路由、阅读、编辑和导出测试。浏览器插件从最终 ZIP 解压安装后验收，不用源码预览代替发行验证。

## 设计依据

- [Notion 外观设置](https://www.notion.com/zh-cn/help/account-settings)：采用浅色、深色、跟随系统及本设备偏好的交互习惯，不复制其品牌资产。
- [Apple 布局指南](https://developer.apple.com/design/human-interface-guidelines/layout)：用对齐、分组和层级帮助阅读，让关键操作靠近当前内容。
- [社区 anti-ai-slop-ui 设计参考](https://github.com/rwcod/anti-ai-slop-ui/blob/main/SKILL.md)：参考其避免模板化大首屏与重复卡片的讨论。这里的黑白配色和字号限制来自本产品要求，不把社区意见当成统一审美结论。

后续新增页面复用现有 token 和组件，不另造暖色品牌主题。修改视觉时同步实际截图和主题行为测试。
