# 集见本地插件

**不需要工作台账号，也不需要安装 Node。** 下载对应浏览器的 ZIP，解压后即可加载。插件暂未上架 Chrome / Edge 商店。

[下载最新正式版](https://github.com/mitang-ai/zsxq-caiji/releases/latest)　[在线安装说明](https://zsxq.51wanai.com/plugins)

## 安装

1. 从发行页下载 `jijian-chrome-v1.2.1.zip` 或 `jijian-edge-v1.2.1.zip`，解压到固定目录。
2. 打开 `chrome://extensions` 或 `edge://extensions`，启用「开发者模式」。
3. 点击「加载已解压的扩展」，选择含 `manifest.json` 的目录。
4. 固定工具栏图标，点击打开侧栏。完整页面用于阅读、选材、加工和导出；快捷键是 `Alt+Shift+J`，被占用时可在浏览器快捷键设置中调整。

想核对下载文件，可从同一发行页取 `SHA256SUMS`。Windows 使用 `Get-FileHash -Algorithm SHA256 <zip路径>`；Linux/macOS 使用 `sha256sum` 或 `shasum -a 256`。

## 第一次使用

先打开知识星球，登录自己的账号，再回到插件选择星球、成员和时间范围。第一次授权只同意你要访问的域名。建议先采一小批，核对作者 ID、原文与覆盖说明，再扩大范围。

模型配置可以跳过。阅读、批注、选材和导出都不要求模型 API；加工时需要你配置 API，选定文本会发给该服务，可能计费。插件不导出 Cookie，也不自动上传历史材料。

## 更新与迁移

**先备份，后更新。** 在「导出与备份」导出本机备份并检查文件能下载，再进行操作。

- 在同一浏览器更新：退出正在执行的任务，覆盖原插件目录内的发行文件，然后在扩展管理页点击「重新加载」。保留原目录可保持开发者扩展标识；不要先卸载。
- 从原「星笺」版本更新：名称改为集见，但 IndexedDB、设置、保险箱与配对协议的内部标识保持不变。若原目录不是当前目录，优先原地更新，或先备份再在新插件中恢复。
- 跨浏览器或换电脑：先安装，再通过备份恢复。原件是否齐全取决于备份的覆盖情况，请核对恢复反馈。
- 卸载扩展、清除浏览器站点数据或丢失保险箱口令，可能导致资料或凭据无法恢复。备份不包含可直接使用的明文 Key 和 Cookie。

## 常见卡点

| 现象 | 先检查 |
| :--- | :--- |
| 加载失败或找不到清单 | 是否选到包含 `manifest.json` 的目录，而不是 ZIP 或上一层目录 |
| 读取来源失败 | 知识星球网页是否仍登录；是否授权对应来源；当前账号是否能看到这条内容 |
| 模型失败或返回未知 | 核对 API 地址和模型。请求结果未知时先查账单与任务记录，不自动重放 |
| 导出缺少原件 | 核对附件覆盖说明，失败原件不冒充已下载；重新采集需要确认权限和预算 |
| 同步没有入库 | 「本机保存」与「工作台确认入库」不是同一状态；核对配对、预览及目标回执 |

反馈请使用仓库 Issue。附浏览器版本、插件版本、步骤和脱敏错误，不附 Key、Cookie、私人帖子或备份文件。
