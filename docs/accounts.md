# 注册和保存账号

登录页与注册页都提供「一键创建账号密码」，无需填写邮箱。按钮在浏览器用安全随机数生成独立账号和 28 字符密码，再通过工作台原有接口创建个人账号。

## 一键创建

1. 点击「一键创建账号密码」，等待页面确认账号已创建。
2. 点击「复制账号密码」或「下载账密文件」。密码默认遮挡，也可以点击「显示密码」后手动保存。
3. 核对保存内容，再勾选「我已妥善保存账号和密码」，进入工作台。
4. 下次在登录页填写保存的系统账号和密码，也可继续使用原有邮箱账号。

**请妥善保管账号和密码，不要分享或上传到公开位置。** 下载文件含明文密码，请存入密码管理器或加密位置。应用不把生成的明文密码写入 localStorage、sessionStorage 或数据库；复制、下载是用户主动选择的保存方式，服务器仍按原有规则保存密码哈希。

自动账号使用保留的 `.invalid` 域名作为登录标识，**不是邮箱，不会收到邮件**。账号恢复仍按实例管理员提供的站外恢复流程进行，不承诺自动邮件找回。

## 中断怎么办

创建结果不确定时，不会自动换一组账号再次注册。页面保留这组账密，点击「重试创建或登录」会先核验是否已创建；仅在登录明确无效时用同一组账密继续创建。

若复制失败，可下载文件或显示密码后手动保存。下载按钮只将文件交给浏览器，需自行检查下载结果。离开或刷新页面后无法再次查看原密码，请先保存；浏览器的离开提示不能代替用户备份。

工作台身份与知识星球登录、模型 API Key 是独立的。创建账号不会连接来源、采集内容、调用模型或同步插件资料。
