# 功能与边界

## 采集：两类连接与本地补充

Web 支持用户私有的官方 MCP 连接，以及独立网页浏览器登录连接。后者不依赖球主是否开启官方 Skill/MCP。浏览器连接使用独立持久 profile，不复制 Codex 内嵌浏览器或用户 Chrome/Edge 登录资料。来源账号核验、星球范围、成员字符串 ID 和选定连接始终记录；切换通道只能使用同一已核验账号，不把权限拒绝静默当成成功。

采集选择星球、成员、起止时间、主帖/回答/评论、讨论/附件和分页预算。列表命中后读主题详情，长文走固定 article-ID 路线，评论按真实游标串行分页。作者主帖、作者回答、其他人的讨论、可观察的子回复分别归属；昵称候选不代表完整成员目录，不把全站足迹当成当前星球全部内容。

原件通过实际业务接口返回的 URL 下载并校验哈希，单件不超过 50 MiB。原图保留原件；无法核验的 CDN、不可见文件、未观察到的嵌套回复分页明确 partial/inaccessible，不猜测补齐。TXT/Markdown/CSV/JSON/HTML 可提取文本；DOCX/PDF 在有时限和内存参数的 worker 中解析。PDF 最多 500 页、文本最多 100 万字符；扫描件不冒称 OCR。保存原件与提取结果是两回事。

## 整理与阅读

- 收件箱、资料库：全文查询、星球/作者/阅读状态/个人标签筛选，保存视图、收藏、批量选择、归档。
- 阅读器：只读来源正文、完整覆盖说明、固定历史版本、个人高亮/批注/位置；列表摘要不用于正文批注校验。
- 专题：手动选材或规则筛选，冻结成明确材料版本集合；动态专题不会令已有成果引用自动改绑最新原文。
- 成员研究：当前星球 + `author_id` 范围入口，选材与时间线阅读；不承诺未采集内容已齐全。
- 四主题、独立密度/阅读字号/高对比、键盘操作和响应式导航；千条材料分批展开，离线错误保留上下文。

## Agent：有计划、有预算、有人工落点

12 个模板：单帖深读、讨论综合、成员研究、日报/周报、专题精选、带引用问答、SOP、案例与工具、FAQ、观点对照、学习路径、持续跟进。目标可自行填写，流程可以保存复用。

每个任务冻结输入版本，显示模型目的地、字符数、调用次数、输出 token 上限、执行位置。默认人工批准。用户主动保存的自动批准流程只能在预授权范围内工作；外部 MCP 令牌不能扩大选材、获取来源登录态或代替人工批准。将人工前稿交给模型必须在计划中列为额外外发输入，并再次人工批准。

所有成果带固定材料引用，保持草稿。人工修改使用 base revision 冲突校验并追加历史；后续分析产生独立提案，可比较、拒绝、手动采纳。来源更新标记 stale，不覆盖人工成果。不提供无边界自主浏览、shell 或任意 URL 工具。

串行任务提供明确事件、暂停/取消/断点。模型调用结果未知默认不重放；重试需要确认重复计费风险，所有计费尝试仍计入原预算。已付费但结构无效的输出保留供人工处理，不通过再次调用掩盖错误。预算用尽需新计划，不静默加预算。

采集的「仅重试失败项」只处理同任务已知主题的失败阶段，不重扫首页、不扩大分页范围。分批导出只包含该任务实际保存的固定修订；旧任务缺少回执时不拿当前整库替代。

## 本地插件与沉淀

Chrome/Edge 同源 MV3 插件包含侧栏和完整扩展页。IndexedDB 保存资料/修订、专题、批注、人工稿历史、任务和本地附件。自配 Chat / Responses / Anthropic Provider，直接连接用户授权的精确 origin；可选择临时 Key，或使用需手动解锁的口令加密保险箱。忘记口令不能恢复 Key。

Markdown/CSV 导出、带原件可移植 ZIP、备份恢复、工作台配对与显式同步。ZIP 入库前检查摘要、路径、大小及原件 SHA-256；实际引用历史随成果包自包含，并在预览中告知。仅成果 Markdown 则不附引用原文。同步逐片上传、幂等回执，以服务端实际材料 ID 为保存依据；不会上传 Cookie、模型 Key 或其他未选择材料。

## 多空间与维护

个人空间仅创建者可见；团队空间按成员角色授权。连接和 Provider 凭据归个人，不随团队共享。分享默认不带原文/附件，需要显式选择且确认引用材料；被移除成员和撤销设备令牌即时失效。

提供私有本地 IPC 启停、单执行器锁、冷备/恢复、离线完整性检查与一次性账号恢复令牌。没有模拟邮件系统。Linux 发行包本地构建，服务器只解压运行；每台目标机器的系统依赖和资源容量都须单独核验，不自动在服务器安装/编译。

## 明确不宣称的能力

没有 OCR、音视频转写、embedding 向量库、外部知识系统自动写入、浏览器商店发布或无限运行的定时全量采集。持续跟进模板是明确创建/批准的任务，不是隐藏定时器。知识沉淀系统的下一阶段接入基于现有 TransferBundle、设备配对和有限 MCP 契约，不靠共享用户凭据。

真实外部验收和未通过项见 [verification.md](verification.md)。
