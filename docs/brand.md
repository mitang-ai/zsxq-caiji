# 集见的识别与使用

**集内容，见门道。** 名称是集见，拼音辅助标识为 JIJIAN；主句是「好内容，别只收藏。」产品说明是「把星球里的讨论，整理成用得上的知识。」

标记是一张斜切角纸页，被非对称 J 形托架接住。绘画模型探索后，以两个路径重新绘制成单色 SVG。不是从生成图截取一块当小图标。

![单色标记](assets/brand/mark.svg)

## 资产

- `mark.svg`：主版。`mark-white.svg`：反白。
- `social-card.png`：1200 × 630 分享预览。Web 构建将其输出为带哈希的资源。
- 插件 `icons/`：16、32、48、128px PNG 与 SVG，Chrome 和 Edge 同源。
- `shared/brand.ts`：对外名称、发行版本和两条矢量路径。
- `scripts/brand-assets.ts`：本地重生成资产。使用已有 PDF 运行依赖中的 canvas，不调用在线模型、不触及用户数据。

主色黑 `#181818`、白 `#FFFFFF`。界面只有浅色、深色与跟随系统，不再提供暖纸或雾蓝主题。旧主题偏好自动映射为浅色，其他阅读偏好与存储标识不变。业务错误和警告保留语义色，不拿彩色做品牌装饰。

Logo 在导航中使用 26–32px，不占据首屏。没有自动播放的品牌动画；两条路径保留独立，便于将来按真实交互制作动效。字标使用系统字体，不使用大字营销海报布局。详细规格见 [前端样式规范](frontend-style.md)。

## 命名边界

对外名变更不等于数据库迁移。`XINGJIAN_*`、`xingjian.*`、数据库和配对内部标识继续保留。README 的两张信息图是流程示意，真实界面截图另存验收证据。

名字已有其他领域使用者；未完成商标与商店相似标记审查，不声称全球独有。品牌素材随本仓库 MIT 许可提供，不代表名称排他权。字标使用系统字体，不捆绑未授权字体文件。
